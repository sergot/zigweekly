## Language & compiler

- [`std.Target` CPU feature curation (#37404)](https://codeberg.org/ziglang/zig/pulls/37404) - merged: many CPU features that were really codegen options in disguise are removed, and a feature should now only describe facts about the machine. Follow-up curation in [#37466](https://codeberg.org/ziglang/zig/pulls/37466).
- [`zig objdump` for ELF (#37478)](https://codeberg.org/ziglang/zig/pulls/37478) - merged, together with more linker tests for the new `Elf2` linker.
- [macOS headers updated to SDK 27.2 (#37473)](https://codeberg.org/ziglang/zig/pulls/37473) - bundled libc headers now follow Xcode 27.2.
- [#19674 rejected while #5038 is accepted](https://ziggit.dev/t/19674-is-rejected-but-5038-is-accepted/18107) - Ziggit thread on what the rejection means for `const x: [_]u8 = .{ ... }`, alongside the accepted requirement to write `const a: T = .{}` instead of `T{}`. Commenters are speculating and nothing is decided there.

## Language & compiler

- [compiler: some performance and peak RSS optimizations (#37624)](https://codeberg.org/ziglang/zig/pulls/37624) - merged: in mlugg's benchmark of building the std tests, peak memory drops by 28% with the self-hosted x86_64 backend and by about 10% with LLVM.
- [Sema: support concatenating vectors (#37606)](https://codeberg.org/ziglang/zig/pulls/37606) - merged: `++` now works on two vectors and lowers to a shuffle, for now both sides must be vectors so literals need a type annotation.
- [hexdump support in objdump, new Io.Terminal style API (#37680)](https://codeberg.org/ziglang/zig/pulls/37680) - merged: `zig objdump` gains a hexdump mode, and `std.Io.Terminal` gets a new API for colors and styles that avoids emitting redundant escape sequences.
- [Elf2: implement merge sections (#37648)](https://codeberg.org/ziglang/zig/pulls/37648) - merged: the new ELF linker now handles merge sections, which shrinks a compiler statically linked to LLVM by 36M (10%). A follow-up, [#37664](https://codeberg.org/ziglang/zig/pulls/37664), adds support for input objects with 0xff00 or more sections.
- [`std.Target`: rename `Arch.aarch64_be` to `aarch64be` (#37677)](https://codeberg.org/ziglang/zig/pulls/37677) - merged, so code that names the old enum field needs updating.
- [`std.Target`: bump baseline Windows version to `win10_rs5` (#37705)](https://codeberg.org/ziglang/zig/pulls/37705) - merged: the default minimum Windows version is now 1809, since Microsoft no longer supports base `win10`.
- [`std.Target`: require an explicit CPU model for `amdgcn` and `avr` (#37766)](https://codeberg.org/ziglang/zig/pulls/37766) - merged: these targets have no meaningful baseline CPU, so target resolution now asks for one.
- [Dwarf2: restructure debug info (#37739)](https://codeberg.org/ziglang/zig/pulls/37739) - merged: the self-hosted DWARF output now uses one compile unit per Zig compilation unit, fixing line info for inline calls across units.
- [crypto.tls: only accept RSASSA-PSS for RSA signatures in TLS 1.3 (#37757)](https://codeberg.org/ziglang/zig/pulls/37757) - merged: the TLS client used to accept RSA-PKCS#1-SHA1 even though TLS 1.3 removed it. In the same batch, [#37755](https://codeberg.org/ziglang/zig/pulls/37755) makes `crypto.asn1` struct decoding strict and fixes several decoder bugs.
- [crypto.ff: add batch modular inversion (#37716)](https://codeberg.org/ziglang/zig/pulls/37716) - merged: `invertBatch()` uses Montgomery's trick to replace all inversions but one with multiplications.

## ZLS

- [Rename `packed` to `bitpack` (#3326)](https://github.com/zigtools/zls/pull/3326) - ZLS follows the language change from `packed` to `bitpack`, now that it has reached the master tarballs.
- [Add known error sets (#3319)](https://github.com/zigtools/zls/pull/3319) - merging an unknown error set with known ones now keeps the known errors instead of resolving to unknown.
- [Preserve pointer type attributes (#3321)](https://github.com/zigtools/zls/pull/3321) - ZLS now keeps `allowzero`, `align`, `volatile` and `addrspace` on pointer types.
- [Exclude coercible values from type resolution (#3325)](https://github.com/zigtools/zls/pull/3325) - `noreturn`, `@compileError` and `undefined` are now ignored when other branches have a known type.
- [Fix completion crash on unknown tagged union payload type (#3320)](https://github.com/zigtools/zls/pull/3320) - fixes a crash reported in #3317.
- [Support zig 0.18.0-dev.1260+833623422 (#3337)](https://github.com/zigtools/zls/pull/3337) - ZLS master keeps up with the latest Zig master.

## Community projects

*Compiled from public posts. Want something removed or credited differently? [Open an issue or pull request](https://github.com/sergot/zigweekly) or email hello@zigweekly.com.*

From the Ziggit thread [What's everybody working on? (November edition)](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173):

- [lalinsky](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/72) released zio 0.20 and dusty 0.6, with more flexible routing and middleware, plus a new TLS library based on AWS-LC.
- [lohann](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/71) is reimplementing Apple's libc in pure Zig as [libxnu](https://codeberg.org/lohann/libxnu/src/branch/main), Apple silicon only for now.
- [fearedbliss](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/76) released [Cactus](https://codeberg.org/fearedbliss/Cactus) 5.8.0, a Diablo II Worldstone Manager, now on Zig 0.17.1 and the latest DVUI.
- [guidoschmidt](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/74) is turning their [Advent of Code solutions](https://codeberg.org/guidoschmidt/advent-of-code) into a reusable framework ahead of this year's event.
- [ericlang](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/68) now has four terrain generators in their random lemmings-style game and is working on trap placement.
- [andyleclair](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/79) got image textures working in their ray tracer using [zstbi](https://github.com/zig-gamedev/zstbi).
- [lukeflo](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/80) is finishing [content filtering for plain text files](https://codeberg.org/lukeflo/lui/pulls/20) in lui, a step toward using it for notes.
- [zeptogon](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/81) sped up the raymarcher in their terrain viewer for GIS data and hopes to release a beta with source soon ([video](https://www.youtube.com/watch?v=RmZQR_-7Zfg)).
- [threeaccents](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/83) wrote [zancudo](https://github.com/threeaccents/zancudo), an epoll-based MQTT 3.1.1 broker that now runs the automation on their farm.
- [xuckless](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/86) is optimizing [Anole](https://github.com/xuckless/anole), a backend framework, and plans C bindings for other languages.
- [diamondjubilee](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/91) is building mola, a Navidrome music player with DVUI and their first Zig project.
- [lhp](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/92) has a pure Zig Wayland client with its own protocol scanner and xkbcommon implementation, aiming at a photo tool that decodes Nikon NEF files.

Also on Ziggit:

- [Shinobi: A Ninja build to Zig build translator](https://ziggit.dev/t/shinobi-a-ninja-build-to-zig-build-translator/18511) - mdavisprog released [shinobi](https://github.com/mdavisprog/shinobi) v0.1.0, a library that translates `build.ninja` files into the Zig build system to make C and C++ libraries easier to build.
- [Should Zig have a dedicated syntax for union initialization?](https://ziggit.dev/t/should-zig-have-a-dedicated-syntax-for-union-initialization/18443) - IntegratedQuantum finds union initialization verbose and the thread compares alternative syntaxes.
- [Aspect](https://ziggit.dev/t/aspect-a-library-for-creating-energy-efficient-guis/18557) - nullclyze started [Aspect](https://codeberg.org/nullclyze/aspect), an early-stage retained-mode GUI library on top of raylib that aims to use resources only when needed.
- [WINS](https://ziggit.dev/t/wins-runtime-re-hoster-and-pe-mach-o-binary-loader-in-zig-for-linux/18533) - DannyBaanks is writing [WINS](https://github.com/DannyBaanks/WINS), an experimental runtime for Windows binaries on Linux without Wine, tested with games such as Fallout: New Vegas and Cuphead.
- [xxd](https://ziggit.dev/t/xxd-print-out-binaries-as-hexes/18563) - peterino2 shared [a 300-line xxd](https://codeberg.org/peterino2/xxd) they use for debugging serialization.
- [Zig IDE](https://ziggit.dev/t/an-introduction-to-zig-ide-an-open-source-cross-platform-development-environment-for-the-zig-programming-language/18532) - kritarkri introduced [Zig IDE](https://github.com/kritarkri/Zig-IDE), a Monaco-based desktop IDE dedicated to Zig.

New repositories:

- [zean](https://github.com/okcontract/zean) - translates Zig's AIR into executable Lean models so you can write contracts and proofs about Zig functions.
- [juno](https://github.com/thijsrijkers/juno) - a modal terminal text editor with fuzzy finding, a project tree and multi-file search built in.

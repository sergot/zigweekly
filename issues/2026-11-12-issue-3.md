## Language & compiler

- [Sema: clean up comptime deref logic (#37524)](https://codeberg.org/ziglang/zig/pulls/37524) - merged: slice special casing moves out of the main load path into a new `analyzeRefDeref` function, resolving [#37148](https://codeberg.org/ziglang/zig/issues/37148) and [#37101](https://codeberg.org/ziglang/zig/issues/37101).
- [Elf2: init/fini array priority (#37539)](https://codeberg.org/ziglang/zig/pulls/37539) - merged: the new ELF linker now supports init and fini array priorities, resolving [#37233](https://codeberg.org/ziglang/zig/issues/37233).
- [SPIR-V: fix layout variant selection in buffer blocks (#37502)](https://codeberg.org/ziglang/zig/pulls/37502) - merged. Also merged is #37468, where `@intFromPtr` now emits `OpConvertPtrToU` instead of a fallback that did not validate (its Codeberg page returns an error at the moment, so no link).
- [`crypto.ff`: public modular inversion (#37512)](https://codeberg.org/ziglang/zig/pulls/37512) - merged: adds `invertPublic()`, adapted from BoringSSL and Fiat Crypto, intended for uses such as RSA blinding.

Under discussion:

- [Syntax at the top of file to choose the kind of namespace (#37373)](https://codeberg.org/ziglang/zig/issues/37373) - accepted proposal by andrewrk that lets a file be an enum, union, opaque or packed struct by starting with e.g. `struct;` or `packed struct(T);`, still collecting comments (26 so far) including alternatives such as a file-level `return`.
- [Require fields to be at the top (#37375)](https://codeberg.org/ziglang/zig/issues/37375) - accepted, breaking proposal by andrewrk that fields of structs, enums and unions must come before any declarations, with 36 comments and the debate still going.

- [mattnite](https://ziggit.dev/t/whats-everybody-working-on-november-edition/18173/42) is working on Gauntlet, a hardware-in-the-loop CI system for MicroZig.

## Articles & videos

*Compiled from public posts. Want something removed or credited differently? [Open an issue or pull request](https://github.com/sergot/zigweekly) or email hello@zigweekly.com.*

- [Making a Zig HTTP Server Absurdly Fast](https://www.youtube.com/watch?v=VSxhGJrRM-Q) - Pokelego Dev video on scaling the performance of a Zig HTTP server.
- [Shlemiel the Painter Is Back: How Zig's libc Rewrite Made SQLite 12,000x Slower](https://dennisforbes.ca/blog/microblog/2026/10/the_accidental_12000x_sqlite_slowdown/) - Dennis Forbes traces minutes-long SQLite inserts in a Rust chess analysis service to a performance problem in Zig's libc, with [a Ziggit thread](https://ziggit.dev/t/zig-libc-rewrite-lead-to-12000x-slowdown-in-sqlite/18214) pointing to [a work-in-progress PR (#37417)](https://codeberg.org/ziglang/zig/pulls/37417) that stops string functions like `strchr` from looping over the string more than needed.
- [Integer addition is not associative, or should we put constants to the right?](https://ziggit.dev/t/integer-addition-is-not-associative-or-should-we-put-constants-to-the-right/18254) - Olvilock argues that because overflow is observed per operation, omitting parentheses in a chain of additions changes behavior, prompted by the operator precedence example in the release notes.
- [Libghostty 1.0](https://mitchellh.com/writing/libghostty-1-0) - Mitchell Hashimoto announces that libghostty-vt, the terminal emulation C library extracted from Ghostty, now has a stable library and C ABI.
